# 💰 Expense Tracker Web App

A simple and responsive web application to track daily expenses with category-based organization and real-time total calculation.

## 🔗 Live Demo
https://expense-tracker-coral-phi-10.vercel.app/

## 💻 GitHub Repository
https://github.com/rashmird32/expense_tracker

---

## 🚀 Features

- Add and delete expenses
- Categorize expenses (Food, Travel, etc.)
- Real-time total expense calculation
- Data persistence using LocalStorage
- Clean and responsive UI

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla JS)
- LocalStorage API
